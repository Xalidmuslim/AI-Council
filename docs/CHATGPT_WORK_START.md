# Запуск в ChatGPT Work + GitHub

## Что уже существует
- Главный репозиторий конфигурации: https://github.com/Xalidmuslim/AI-Council
- Профили трёх ролей: .github/agents/programmer.agent.md, arabist.agent.md, tester.agent.md
- Единые правила обмена задачами: docs/AGENT_PROTOCOL.md
- Ранее настроенные инженерные навыки: .agents/skills (только там, где агент может читать соответствующий репозиторий).

## Важно различать
- **ChatGPT Work** может координировать длительные задачи и работать через разрешённые инструменты, но роли из GitHub не становятся автоматически тремя самостоятельными работающими экземплярами.
- **Codex** специализируется на коде, реальной среде разработки, тестах, PR и сборках.
- Файлы в .github/agents/*.agent.md могут использоваться поддерживаемыми **GitHub Copilot custom agents**; это не подтверждение активации этих профилей в ChatGPT Work.
- Для доступа к другому приложению агент должен открыть именно его репозиторий и прочитать его AGENTS.md. Глобальная настройка всех 16 репозиториев этим PR не выполняется.

## Первый запуск вручную
1. В ChatGPT выбери Work. В проекте, где ведутся приложения, создай Work-разговор.
2. Проверь, что разрешён GitHub. Укажи ссылку на этот репозиторий и файлы .github/agents/ и docs/AGENT_PROTOCOL.md.
3. Отправь сообщение ниже, подставив нужный repository и задачу. Для работы с кодом, тестами или сборкой используй Codex, если Work не предоставляет выполнение команд.
4. Разрешай изменения только через отдельную ветку/draft PR. Не включай auto-merge без явного решения. При отсутствии команды запуска тестов ставь NEEDS_CHECK.

## Стартовое сообщение для Work

Координируй роли по этому протоколу, не утверждай, что автономные процессы запущены, если фактически это не так. Для каждого задания укажи реальный repository/ref/commit, собери доказательства и отправь итоговый отчёт. Ничего не сливай в main и не выпускай APK без моего разрешения.
